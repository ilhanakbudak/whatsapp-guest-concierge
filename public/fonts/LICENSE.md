# Bundled fonts

Both are self-hosted rather than loaded from a CDN: the admin interface has to
work on a villa's wifi, and a third-party font request is a render-blocking
dependency on someone else's uptime. The latin subsets together are ~78 KB.

| Font | Version | License |
|---|---|---|
| Inter (variable, latin subset) | v20 | SIL Open Font License 1.1 |
| JetBrains Mono (variable, latin subset) | latest | SIL Open Font License 1.1 |
